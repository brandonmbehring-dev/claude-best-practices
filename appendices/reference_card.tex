\section{Bundled Skills}

\marginnote[Official]{Bundled skills are prompt-driven: they give Claude
a playbook and let it orchestrate using tools.
Unlike built-in commands, skills can spawn
subagents and adapt to your codebase.\sourceurl{https://code.claude.com/docs/en/skills}}

Bundled skills ship with Claude Code and appear alongside built-in commands
when you type \code{/}. They are not fixed logic---they are prompt-based
workflows that Claude executes.

\begin{fullwidth}
\begin{tabular}{@{}lp{8cm}@{}}
\toprule
\textbf{Skill} & \textbf{Description} \\
\midrule
\code{/batch <instruction>} & Parallel codebase changes: researches, decomposes into 5--30 units, spawns one background agent per unit in an isolated worktree. Each agent implements, tests, and opens a PR. \\
\code{/loop [interval] <prompt>} & Run a prompt repeatedly on an interval (default 10 min). Session-scoped polling for deploys, PRs, or recurring checks. \\
\code{/simplify [focus]} & Review recently changed files for reuse, quality, and efficiency. Spawns 3 parallel review agents. \\
\code{/debug [description]} & Troubleshoot your Claude Code session by reading the debug log. \\
\code{/claude-api} & Load Claude API and Agent SDK reference for your project's language. \\
\bottomrule
\end{tabular}
\end{fullwidth}

\section{Hook Types (4 Total)}

\begin{description}
  \item[\code{command}] Runs a shell command (most common). Exit 0 = proceed, exit 2 = block.
    10-minute timeout (configurable).
  \item[\code{http}] POST JSON to a URL (30-second default timeout).
    Best for: webhooks, external service notifications, CI triggers.
  \item[\code{prompt}] Single-turn LLM evaluation (Haiku by default).\newline
    Returns \code{\{"ok": true/false\}}.
  \item[\code{agent}] Multi-turn subagent with tool access (up to 50 turns, 60s default timeout).
\end{description}

\section{Settings Precedence (5 Levels)}

\begin{enumerate}
  \item \textbf{Managed} (\code{managed-settings.json}) --- IT-deployed, highest priority
  \item \textbf{CLI arguments} --- temporary session overrides
  \item \textbf{Local} (\code{.claude/settings.local.json}) --- personal, auto-gitignored
  \item \textbf{Project} (\code{.claude/settings.json}) --- team standards, committed
  \item \textbf{User} (\code{\textasciitilde/.claude/settings.json}) --- global personal defaults
\end{enumerate}

Higher levels override lower. Deny rules are absolute
and cannot be overridden by lower levels.
