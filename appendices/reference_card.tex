\section{Hook Types}

\begin{description}
  \item[\code{command}] Runs a shell command (most common). Exit 0 = proceed, exit 2 = block.
  \item[\code{prompt}] Single-turn LLM evaluation (Haiku by default).\newline
    Returns \code{\{"ok": true/false\}}.
  \item[\code{agent}] Multi-turn subagent with tool access (up to 50 turns, 60s default timeout).
\end{description}

\section{Settings Precedence (5 Levels)}

\begin{enumerate}
  \item \textbf{Managed} (\code{managed-settings.json}) --- IT-deployed, highest priority
  \item \textbf{CLI arguments} --- temporary session overrides
  \item \textbf{Local} (\code{.claude/settings.local.json}) --- personal, auto-gitignored
  \item \textbf{Project} (\code{.claude/settings.json}) --- team standards, committed
  \item \textbf{User} (\code{\textasciitilde/.claude/settings.json}) --- global personal defaults
\end{enumerate}

Higher levels override lower. Deny rules are absolute
and cannot be overridden by lower levels.
