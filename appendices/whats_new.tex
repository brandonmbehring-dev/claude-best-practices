\chapter{What's New}

This appendix summarizes the major changes between editions
for readers upgrading from previous versions.

\section*{v2.8 (March 2026)}

\begin{description}
  \item[Reference Card Expansion (\cref{app:reference})]
    Added 8 built-in commands and 8 CLI flags verified against official docs.
    Notable additions: \code{--bare} (minimal scripted mode), \code{--json-schema}
    (structured output), \code{--max-budget-usd} (cost control), and
    \code{--enable-auto-mode} (Team plan auto-approval).
    Footnote links to complete command list. \code{/review} noted as deprecated.

  \item[Bare Mode (\cref{ch:automation})]
    New subsection documenting \code{--bare} for CI/CD and SDK automation.
    Skips hooks, skills, plugins, MCP, memory, and CLAUDE.md.
    $\sim$14\% faster to API request.

  \item[Model Capabilities Reference (\cref{ch:prompting})]
    New table with max output tokens, context windows, knowledge cutoffs,
    and thinking modes. Complements the pricing table in \cref{ch:enterprise}.

  \item[Auto Mode Prerequisite (\cref{ch:first-session})]
    Margin note clarifying that auto permission mode requires
    \code{--enable-auto-mode} flag and a Team plan or higher.
\end{description}

\section*{v2.7 (March 2026)}

\begin{description}
  \item[Two-Phase Compaction (\cref{ch:context})]
    New subsection explaining how auto-compaction works internally:
    tool outputs are cleared first (cheap, low info loss), then
    conversation is summarized only if needed. Also documents that
    CLAUDE.md fully survives compaction---re-read from disk and
    re-injected fresh.

  \item[PostCompact Hook (\cref{ch:context})]
    New subsection with JSON configuration example mirroring the
    existing PreCompact coverage. Includes the PreCompact/PostCompact
    pairing pattern for automatic state checkpointing across compaction.

  \item[Auto-compaction threshold override (\cref{ch:context})]
    Documents the \code{CLAUDE\_AUTOCOMPACT\_PCT\_OVERRIDE} environment
    variable. Tagged as convergence (undocumented, community-discovered).
    Can lower but not raise above $\sim$83\%.

  \item[CLAUDE.md sizing guidance (\cref{ch:context})]
    Anthropic recommends under 200 lines per CLAUDE.md file and
    under $\sim$500 lines total across all five hierarchy levels.

  \item[Hook events: 24 $\rightarrow$ 25 (\cref{app:reference})]
    Added TaskCreated event. Auto permission mode now documents
    the \code{--enable-auto-mode} flag and Team plan prerequisite.

  \item[Max output tokens (\cref{ch:enterprise})]
    Pricing table now includes max output limits: Opus~4.6 128K tokens,
    Sonnet~4.6 and Haiku~4.5 64K tokens each.
\end{description}

\section*{v2.5 (March 25, 2026)}

Changes from v2.3 (February 2026) to v2.5.

\subsection*{New Chapters and Sections}

\begin{description}
  \item[1M Context Window Strategy (\cref{ch:context})]
    New section covering how the 5$\times$ larger context window changes the game.
    Includes a decision framework (four tiers from $<$30\% to $>$80\%),
    \code{/compact <focus>} for targeted compaction,
    and a PreCompact hook example for state preservation.

  \item[Durable Artifacts (\cref{ch:context})]
    Primary persistence strategy: \code{CURRENT\_WORK.md}, plan documents,
    and git commits outlast compaction and session boundaries.
    Compaction is positioned as a supplement, not the primary strategy.

  \item[\code{/btw}: Zero-Context-Cost Side Questions (\cref{ch:context})]
    Ask questions without growing context.
    The answer appears in a dismissible overlay and never enters conversation history.

  \item[Fast Mode (\cref{ch:prompting})]
    Same Opus 4.6, 2.5$\times$ faster, \$30/\$150 MTok (research preview).
    Toggle: \code{/fast} or \code{Alt+O}. Falls back to standard on rate limit.

  \item[\code{/batch}: Parallel Codebase Changes (\cref{ch:agents})]
    Bundled skill that decomposes work into 5--30 units and spawns parallel
    agents in isolated worktrees. Each agent implements, tests, and opens a PR.

  \item[Agent SDK (\cref{ch:automation})]
    Expanded from a decision box to a full subsection with Python and TypeScript
    examples. Same tools as Claude Code, programmable for production deployment.

  \item[Scheduled Tasks (\cref{ch:automation})]
    Three tiers: Cloud (\code{/schedule}, runs on Anthropic infrastructure),
    Desktop (local machine, persistent), and \code{/loop} (session-scoped polling).

  \item[GitHub Actions (\cref{ch:automation})]
    \code{anthropics/claude-code-action@v1} for AI-powered PR review.
    Triggered by \code{@claude} in any PR or issue comment.

  \item[Remote Control (\cref{ch:automation})]
    \code{/remote-control} connects \code{claude.ai/code} or the mobile app
    to a session running on your machine.

  \item[API Pricing Reference (\cref{ch:enterprise})]
    Model pricing table with Haiku 4.5, Sonnet 4.6, Opus 4.6, fast mode,
    and discount combinations. Includes staleness qualifier.
\end{description}

\subsection*{Corrected Claims}

\begin{description}
  \item[Hook events: 21 $\rightarrow$ 24]
    Added StopFailure, CwdChanged, FileChanged. Full matcher values documented
    for all 24 events (\cref{ch:extending}).

  \item[Hook handler types: 3 $\rightarrow$ 4]
    Added \code{http} type for webhooks and CI triggers (\cref{ch:extending}).

  \item[Permission modes: 5 $\rightarrow$ 6]
    Added \code{auto} (research preview). All six modes documented with
    correct \code{Shift+Tab} cycling behavior (\cref{ch:first-session}).

  \item[Keyboard shortcuts corrected]
    \code{Ctrl+G} opens prompts in the default text editor (not ``the plan'').
    \code{Shift+Tab} cycles through all enabled modes (not a fixed three-mode loop).

  \item[\code{/effort auto} explained]
    Resets effort to the model's default behavior---does not mean ``dynamic per-turn.''

  \item[60\% degradation threshold qualified]
    Clarified as a practitioner heuristic ($\sim$60--70\%) distinct from the
    auto-compaction trigger ($\sim$83\%). For 1M windows, absolute token counts
    matter more than percentages.

  \item[CLAUDE.md line count: both official numbers cited]
    Anthropic recommends under 200 lines per file (memory docs) and under
    $\sim$500 lines total (cost docs). Our 300-line guidance is reframed as a
    practitioner compromise between the two.

  \item[Caching claims qualified]
    ``Up to 60--80\%'' savings now includes ``(workload-dependent)'' qualifier.
    ``Caching beats model downgrading'' now says ``typically saves more.''

  \item[FedRAMP separated from commercial certs]
    Government authorizations (FedRAMP High, IL5) are now distinct from
    commercial certifications (SOC 2, ISO 27001, HIPAA BAA) (\cref{ch:enterprise}).

  \item[Two broken URLs fixed]
    Long-running-agents blog post URL and GitHub Copilot blog post URL
    updated to current locations.
\end{description}
