\addcontentsline{toc}{chapter}{Preamble}

This handbook teaches you to use Claude Code effectively---not by listing
features, but by walking through the workflows where each feature earns its value.

\subsection*{Two Sources of Knowledge}

Every practice is drawn from one of two sources and labeled accordingly:

\begin{description}
  \item[{\color{OfficialPurple}\textbf{[Official]}}] Anthropic's documented recommendation,
    verified against current documentation with source URL.
    Example: \official{Run \code{/init} to generate a starter CLAUDE.md.}
  \item[{\color{PractitionerTeal}\textbf{[Practitioner]}}] Discovered through extensive daily use
    across 20+ projects spanning data science, ML, and software engineering.
    Example: \practitioner{After two failed corrections, \code{/clear} and write
    a better initial prompt.}
  \item[{\color{ConvergenceGold}\textbf{[Convergence]}}] Both sources agree independently.
    Example: \convergence{Verification criteria in CLAUDE.md from day one.}
\end{description}

\subsection*{How This Book Is Organized}

The handbook follows your adoption journey through four parts,
each corresponding to a level of the Claude Maturity Model (\cref{app:maturity}):

\begin{description}
  \item[Part I: Foundations] (\cref{part:foundations}) ---
    What Claude Code is, your first CLAUDE.md, your first session.
    \emph{Takes you from L1 (Conversational) to L2 (Configured).}
  \item[Part II: Personal Practice] (\cref{part:practice}) ---
    Advanced prompting, context management, testing, extensions.
    \emph{Takes you from L2 to L3 (Systematic).}
  \item[Part III: Advanced Craft] (\cref{part:advanced}) ---
    Configuration architecture, agents, project lifecycle, anti-patterns.
    \emph{Takes you from L3 toward L4 (Autonomous).}
  \item[Part IV: Team \& Enterprise] (\cref{part:enterprise}) ---
    Automation, team governance, enterprise deployment.
    \emph{Scaling from L4 to L5 (Enterprise).}
\end{description}

\subsection*{Who This Is For}

\textbf{Primary audience:} Data scientists and ML engineers who have used Claude Code
at least once and want to go from ``it works sometimes'' to ``it works reliably.''
No prior configuration experience assumed.

\textbf{Secondary audience:} DS/ML team leads evaluating Claude for their teams.
\cref{ch:enterprise} is specifically designed to be shared with decision-makers.

\subsection*{How to Read}

\begin{description}
  \item[New to Claude Code?] Start at \cref{ch:principles} and read straight through Part I.
  \item[Already configured?] Start at \cref{ch:prompting} (Part II).
    Skim Part I for anything you missed.
  \item[Experienced user?] Jump to \cref{ch:antipatterns}. Fix what is broken.
    Then read \cref{ch:architecture} for scaling patterns.
  \item[DS/ML team lead?] Read \cref{ch:enterprise} and \cref{app:maturity},
    plus \cref{ch:thinking-partner} and \cref{ch:testing} for DS-specific workflow value.
\end{description}
