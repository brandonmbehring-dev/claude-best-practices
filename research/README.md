# Research

Exploratory scripts and research inputs. **Not part of the book build.**

These artifacts exist to inform content decisions or capture external
material; they do not produce any chapters, figures, or build outputs.

## Contents

| File | Purpose |
|------|---------|
| `extract_vibe_engineering.py` | Docling-based PDF extraction of Manning's *Vibe Engineering* MEAP v2. Outputs markdown, JSON, per-chapter splits, and a companion-repo inventory. Used to survey adjacent practitioner content. |

## Running

Each script is self-contained. See the script's module docstring for
required inputs and output locations. Dependencies (e.g., Docling) are
not declared in the main book's build system; install separately as
needed.
